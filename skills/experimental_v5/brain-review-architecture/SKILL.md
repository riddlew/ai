# Architecture review

Review the requested architecture scope, or investigate bounded candidate issues when no area is specified. Default inline. Inspect actual code, dependencies, ADRs, current decisions and relevant prior reports. Identify observable tradeoffs and limitations; separate established decisions from recommendations. Consult the user before consequential redesign or implementation. Save a review only if requested or necessary for durable cross-session work, not automatically. No approval/status gates or automatic `brain-update`. See `references/architecture-review-details.md` when complex.
