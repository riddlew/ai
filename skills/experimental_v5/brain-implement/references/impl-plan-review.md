# Optional execution readiness review (v5)

Only for complex scope or when the user requests a planning review; never a precondition for code editing. Read the actual request, existing applicable docs and amendments, code, Git state, tests and relevant blockers. Identify a feasible sequence of coherent behaviors, preserved user edits, concrete verification needs and new consequential questions.

No mandatory spec, plan, tasks, execution record or collaboration-mode gate. Inline is automatic; subagents only if explicitly requested. If an optional `execution.md` already exists, preserve its verified history and true review base, but do not treat checkboxes as proof or request approvals.

Do not run `brain-update` or generate task files just to fill a checklist.
