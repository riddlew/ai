# Optional feature execution record (v5)

```markdown
# Feature execution

Objective:
- <requested result>

Review base:
- <verified commit when needed>

Current focus:
- <next coherent behavior>

Completed:
- <verified work>

Remaining:
- <uncompleted scope>

Active amendments:
- <IDs if any>

Blockers:
- None

Verification:
- <actual test/command and outcome>
```

Execution state is a concise factual resume aid, not a governing plan or approval ledger. No mandatory checkpoints, status transitions or parent hashes. For small one-session work, do not create a record. A handoff references authoritative decisions rather than repeating them.
