# Explain changes

Default inline; no subagent selection prompt. Scope to the requested file, symbol, branch, diff or functionality; inspect relevant code, callers, tests, and current Git differences. Where intent is documented, follow current authoritative decisions and amendments rather than historical approval status. Distinguish source facts and intent from inference, and describe real code paths with helpful examples.

Explain coherent parts at the user's preferred depth and pause naturally for questions. Never auto-approve a review checkpoint, modify files, call `brain-update`, or run tests unless requested. See `references/explain-details.md` for branch-comparison safeguards.
