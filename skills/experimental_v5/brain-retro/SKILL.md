# Brain retrospective

Only on explicit request. Default inline; never require execution-mode selection. Review concrete evidence of repeated cost, missing context, failed fixes or confusing workflow rules; distinguish actual measured tokens from estimates. Recommend up to three maintainable changes with evidence, tradeoffs and verification, not additional administrative stages. Do not edit files, create tasks or PRs, dispatch agents, or invoke `brain-update` automatically. Refer to `references/retro-details.md` for edge cases.
