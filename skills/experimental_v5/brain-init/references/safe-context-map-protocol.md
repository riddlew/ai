# Optional context-map discovery protocol (v5)

The deterministic `brain-context plan` tool may list candidate documents by feature, branch and source path. It is an accelerator, **not** an exclusion list or mandatory first step. Use current request and context to select relevant sources; read additional root/feature/ADR documents whenever needed. An unlisted relevant source is not permission to ignore it.

Retain correct branch pending-file isolation and `.brain/.notes/` privacy. Treat map hashes and coverage markers as hints, not authorization or freshness guarantees. Do not introduce stale-approval gates, reread all project documentation without reason, or automatically invoke `brain-update`. Only the explicit update workflow changes owned source maps and root knowledge.
