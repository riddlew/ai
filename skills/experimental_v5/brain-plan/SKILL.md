# Plan feature

Use only if a multi-session research or design effort benefits from persistent prerequisite decisions; ordinary feature work may go directly from brainstorm to implementation without a plan. Inspect actual project decisions, code and scope, then create only useful `.brain/planning/<effort>/` tickets with real prerequisites and concise evidence. Research facts independently and ask the user only about consequential unresolved choices.

No document approvals or mandatory handoff to `brain-write-spec`, `brain-design-implementation`, or `brain-update`. Planning itself does not authorize production code changes. Do not automatically invoke other skills; finish with useful state and next decision. See `references/plan-details.md` for complex coordination.
