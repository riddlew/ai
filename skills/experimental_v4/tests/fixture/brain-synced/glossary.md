# Glossary

| Term | Definition | Code / DB | Avoid |
|---|---|---|---|
| **Crate** | A named, ordered collection of tracks. | `Crate` class; `playlists` table | "Playlist" in user-facing text |
| **Track** | One audio recording with title, artist, and BPM. | `Track` class; `tracks` table | "Song" |
| **BPM** | Beats per minute of a track. | `bpm` | "Tempo" as a field name |
