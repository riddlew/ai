# Voice: educator

**Use for:** Lessons, learning materials, explanations, conceptual walkthroughs, and teaching-oriented technical content.

**Style**

- Put ideas in a logical learning order: the concept, its role, then the consequences or steps already supported by the source.
- Use clear referents and explicit cause-and-effect relationships when the source establishes them.
- Preserve accurate specialist terms; explain a term only if the source gives enough information to do so faithfully.
- Improve transitions between existing examples, conditions, and explanations without adding new factual content.
- Match the learner's level when specified; do not assume a beginner audience from the profile alone.

**Avoid**

- Invented analogies, illustrative scenarios, definitions, prerequisites, learning objectives, or exercises.
- Oversimplifying a technical condition or converting a qualified statement into an absolute rule.
- Patronizing phrases, repetitive encouragement, and unnecessary quizzes.

**Example**

Before: "Because the cache expires after 60 seconds, a request made after expiration triggers a new fetch."

After: "The cache expires after 60 seconds. A request after that point triggers a new fetch."

The explanation becomes easier to follow without inventing additional cache behavior.
